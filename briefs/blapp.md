# Blapp

A discovery platform for Black-owned businesses, founded by **Jon Laster**.
Currently expanding from discovery into **e-commerce** so users can transact
directly in-app.

## Current state

- Core discovery (browse, search, save) is live.
- Building out the e-commerce layer: storefronts, cart, checkout.
- React Native / Expo app (see the `blapp/` project in the monorepo).

## Decisions log

- **E-commerce next.** Discovery alone doesn't capture enough value; close the
  loop with transactions.
- **Mobile-first.** The audience is mobile-native.

## Open questions

- Payments provider + fee structure for sellers.
- Onboarding flow for business owners to set up a storefront.
