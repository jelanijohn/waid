# Solaris

A simple, low-maintenance mobile game whose primary goal is **ad revenue**.
Not trying to make art here — trying to make something fun-enough that retains
players long enough to monetize via rewarded + interstitial ads.

## Current state

- Paused while Gluefi and Blapp take priority.
- Core loop prototyped; needs polish + an ad SDK integration.

## Decisions log

- **Ad-funded, not paid.** Lower friction, broader top-of-funnel.
- **Keep scope tiny.** One mechanic, executed well.

## Open questions

- Which ad network (AdMob vs. a mediation layer)?
- What's the single core mechanic worth shipping?
