# The Thinking Room

Research into a **room or device** that reliably pushes its occupant into a
specific mental state — primarily **flow** — using music (and possibly light,
temperature, and other ambient cues).

## Current state

- Literature review on flow induction, neuroacoustics, and binaural/isochronic
  audio.
- **Blocked:** need a clearer hypothesis to test before building anything.

## Decisions log

- **Music as the primary lever.** Cheapest, most-evidenced path to state change.
- **Room vs. device.** Start with a software prototype (headphones) before any
  physical build.

## Open questions

- What's the measurable proxy for "flow" we can instrument cheaply?
- Generative/adaptive audio vs. curated playlists?
